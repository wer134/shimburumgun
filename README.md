# 심부름꾼 (The Errand Runner)

한국 저승 설화를 바탕으로 한 **Java 콘솔 텍스트 RPG**.

이승과 저승 사이 "사이길"에 갇힌 주인공이, 저승사자 강림에게 심부름 셋을 완수하면 돌려보내 주겠다는 거래를 제안받는다.

## 핵심 설계

혼력(魂力)이라는 **단 하나의 자원**을 세 곳에 나눠 쓴다.

| 쓸 곳 | 얻는 것 | 잃는 것 |
|-------|--------|--------|
| 저승낫 강화 | 전투력, 히든 엔딩 자격 | 인간으로 남을 가능성 |
| 천도(薦度) | 공덕 | 강해질 기회 |
| 숨돌이 | 체력 | 위 둘 모두 |

기대 예산으로는 셋 중 둘까지만 감당된다. 매 상점마다 "강해질 것인가, 선하게 남을 것인가"를 다시 정해야 하고, 그 이력 전체가 3장의 **업경대(業鏡臺)** 앞에서 그대로 재생된다.

엔딩은 4종. 공덕과 강화 단계는 서로 반대 방향으로 작동하므로, 공덕이 높아도 낫을 너무 갈았다면 이승으로 돌아갈 수 없다.

## 설화 출전

각 장은 실재하는 한국 설화 한 편씩을 뼈대로 삼는다.

| 장 | 설화 | 가져온 것 |
|----|------|----------|
| 프롤로그 | 〈차사본풀이〉 적패지 유래담 | 까마귀가 명령서를 잃어 "순서 없는 죽음"이 시작됐다는 유래. 주인공은 명부에 없는 죽음이라 사이길에 걸린다 |
| 1장 | 밀양 아랑 설화 | 억울하게 죽어 대숲에 버려진 원혼. 해원의 조건은 퇴마가 아니라 **끝까지 들어주는 것** |
| 2장 | 〈차사본풀이〉 동방삭 + 〈멩감본풀이〉 사만이 | 숯을 희게 씻는다는 거짓말로 삼천갑자를 낚는 수법. 그 수법을 쓸 것인가 |
| 3장 | 〈이공본풀이〉 서천꽃밭 + 업경대 | 환생꽃이 이승 귀환의 수단이고, 꽃밭은 **부정한 자를 들이지 않는다** |

전거와 각색의 구분은 [GDD 11장](GDD.md#11-설화-출전典據-매핑)에 표로 정리했다.

## 구현 현황

아직 코드 없음. 기획 단계.

| 우선순위 | 항목 | 상태 |
|---------|------|------|
| 1 | 스토리렛 엔진 + 플래그 시스템 | 미착수 |
| 2 | 혼력 경제 + 강화 시스템 | 미착수 |
| 3 | 스토리 텍스트 (프롤로그 + 3장 + 엔딩 4종) | 미착수 |
| 4 | 업경대 회상 시스템 | 미착수 |
| 5 | 전투 시스템 | 미착수 |
| 6 | 세이브/로드 | 선택 구현 |

## 밸런스 수치에 대하여

GDD의 확률표와 지급량은 몬테카를로 시뮬레이션으로 검증한 값이다. 확률표를 수정할 때는 **"기대 예산 380 혼력으로 +5 도달률이 5~15% 범위인가"** 를 반드시 재확인할 것. 이 범위를 벗어나면 히든 엔딩이 너무 흔해지거나 사실상 닫힌다. 근거는 [GDD 10.3](GDD.md#103-밸런스-회귀-테스트).
